## 2. Phân tích luồng

### 2.1 Happy path (E2E)

1. **[P1a]** TCTD chọn Phân loại "Tệp có cấu trúc khác" → kéo thả/chọn ≤10 tệp → client kiểm tra TT01–TT09, DH01, DH03, DL01, DL02 → tất cả "Hợp lệ" → nhập Mô tả tệp/Ghi chú (không bắt buộc) → **Lưu & Gửi báo cáo** → MH 3.2 tải tuần tự: Chờ tải lên → Đang tải (%) → Tải lên thành công.
2. **[P2]** Hệ thống kiểm tra tên tệp (và trùng tên với tệp đã tiếp nhận, ngày báo cáo ≤ ngày hệ thống) → **Đã tiếp nhận** (xanh) → giải nén → chuyển Quy trình kiểm tra nội dung (XL07) → gửi thông báo "Đã tiếp nhận".
3. **[P3a]** Kiểm tra cấu trúc = Hợp lệ → Kiểm tra hệ thống chỉ tiêu = Hợp lệ (hoặc Chờ xem xét → CB chấp nhận) → Lưu CSDL CXĐ = Thành công (mỗi sheet/lớp → 1 bảng raw).
4. **[P3 Luồng 2]** Có quy tắc Đã phê duyệt phù hợp → Chuyển đổi tự động thành công → kích hoạt XL07 trên dữ liệu 1457.
5. **[P1b]/[P2a]** TCTD và CB CIC tra cứu, xem chi tiết trạng thái.

### 2.2 Alternative paths

- **A1** CB đánh dấu **Không cần chuyển đổi** → khai thác trực tiếp bảng raw (P3, P3a popup Chuyển đổi).
- **A2** Chưa có quy tắc → **Chưa có bộ chuyển đổi / Cần chuyển đổi thủ công** → P3h cấu hình mapping → Preview (P3i) → Xác nhận lưu (Lý do bắt buộc) → Chuyển đổi thủ công thành công → XL07.
- **A3** Tại P3h: **Lưu quy tắc chuyển đổi** → quy tắc "Mới tạo" → (Gửi phê duyệt) → Chờ phê duyệt → Đã phê duyệt → dùng tự động cho tệp sau.
- **A4** Quản lý quy tắc độc lập: Thêm mới (P3b) / Sửa (P3c, chỉ Mới tạo/Từ chối) / Xóa (P3d) / Phê duyệt-Từ chối / Ngưng sử dụng / Kích hoạt lại (P3e).
- **A5** Kiểm tra hệ thống chỉ tiêu **Chờ xem xét** → CB Chấp nhận (→ Hợp lệ → Lưu raw) hoặc Từ chối (→ Tệp lỗi).

### 2.3 Exception paths

- **E1** Tệp vi phạm rule client (TT/DH/DL) → "Không hợp lệ" + tooltip mã lỗi → nút Lưu & Gửi disable (P1a).
- **E2** Lỗi tải lên (mất kết nối) tại MH 3.2 (P1a) → "Lỗi tải lên"/"Lỗi tải file" (P1b) — Q19, Q21.
- **E3** Tên tệp sai / trùng tên tệp đã tiếp nhận → **CIC từ chối** + thông báo lý do (P2) — Q13, Q32.
- **E4** Kiểm tra cấu trúc = Tệp lỗi (BUS-260…263) → dừng, không kiểm tra chỉ tiêu (P3a) — Q34.
- **E5** Kiểm tra chỉ tiêu vượt ngưỡng bị từ chối → Tệp lỗi (P3a) — Q40, Q41.
- **E6** Chuyển đổi tự động thất bại → chuyển xử lý thủ công (P3 Luồng 2) — Q38.
- **E7** CB không hoàn tất chuyển đổi thủ công → "Không thể chuyển đổi" (P3) — Q38.
- **E8** Trùng tên quy tắc (BUS-265/266) — Q46, Q47; trùng tên tệp kết quả (popup Trùng tên tệp) — Q61.
- **E9** Phê duyệt/Từ chối đồng thời → BUS-78 (P3e) — Q54.
